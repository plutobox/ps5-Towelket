# Original game release order

The Library shows the original Japanese game's release year and its position
in the Towelket series. These are not translation, upload, or PS5 port dates.
Years are used where a reliable exact date is unavailable. Catalog order follows
the [English translation team's release-order guide](https://towelkettranslations.wordpress.com/towelket-english-download/).
END ROLL is a separate game and has no Towelket series number.

Towelket 6 / Reverse uses the 2009 date and fourth position given by the
English translation team for the original Reverse/Ura game. Later revised
versions titled Towelket 6 have different dates.

Maiden Bomb Invaders was briefly released on the author's blog in 2014 and
then reissued publicly in 2015. The catalog uses the original 2014 year; see
[contemporary release coverage](https://www.moguragames.com/taorukettorelease/).
The English translation team's page does not give an original release date.

The remaining Towelket years are stated on the linked translation pages.
END ROLL's original distribution page records June 2, 2016.

The optional catalog fields are `original_release` (a year or ISO date string)
and `series_order` (a positive integer). Existing custom catalogs may omit them.
